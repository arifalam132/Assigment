# Assignment – Frontend Migration

This project rebuilds the existing frontend using **SvelteKit** while keeping the backend unchanged.

The goal was to remove the old static frontend and replace it with a modern, maintainable setup using TypeScript.

## Tech Stack
- SvelteKit
- TypeScript
- Zod (form validation)

## What was done
- Old frontend removed
- New SvelteKit frontend added
- Login form implemented using server actions
- Validation handled with Zod
- Reusable UI components created
- Backend APIs consumed as-is
